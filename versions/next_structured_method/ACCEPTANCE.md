# 验收清单（2026-09-08）

状态：实现和 CPU 回归已完成；正式 GPU / 全量实验仍待执行。勾选项仅在所述范围内成立，不沿用原 v9 测试成绩。

## 数据、角色与统一目标

- [x] 普通 JSONL 四字段、三个原始划分的真实 SHA-256 / 数量 / 唯一性 / split 隔离通过；拒绝依赖图目录和字段。
- [x] 原始数据字节保持不变，不重新切分、不从 DC 数据转换冒充普通数据。
- [x] 真实归档 tokenizer 下全部普通数据通过长度预算及数字答案检查。
- [x] PLAN → SOLVE1…K → READOUT 维度随 K 一致；默认八 latent / 16 维动作。
- [x] 教师转移连续不重叠分段、覆盖与闭合；短 CoT、空槽、零目标和空 CoT 有明确处理。
- [x] 同一个目标供 SFT / SOLVE 累计几何 / 过程评分消费；没有旧全角色 BRIDGE 目标并行启用。
- [x] 学生 latent / 生成入口只接收问题；锚点为普通 CoT 训练标签，推理自行生成。

## 固定教师和 SFT / RL

- [x] 缓存校验教师、base、tokenizer、数据、投影、代码、配置、库版本、精度和逐样本内容；损坏/错误缓存拒绝。
- [x] 缓存仅 train；Stage2 评分副本和参考策略固定且持久化，学生 PLAN head 保持可训练。
- [x] 固定随机种子的 SFT 高斯扰动可重现，均值路径不额外消耗 RNG，默认扰动与 RL 初始标准差一致。
- [x] 原始 softmax 采样与重放 log-prob 在 tiny-Qwen 上一致，兼容首 EOS / PAD=EOS。
- [x] 保存的随机动作固定；READOUT 重算且在受控非零答案优势下有有限非零专属 head 梯度。
- [x] 组边界隔离；READOUT 过程信用向前传播，终局答案奖励不在过程 return 重复出现。
- [x] 过程优势 std 下界、截断和末次更新退火有测试；不是潜在正确性的证明。
- [x] 固定 token/action 尺度，PAD/长度测试；双 CPU/Gloo 实际训练与单进程均值规约在容差内一致，末批空 rank 无重复题。
- [x] loss 分量、答案/过程增量、KL、replay、总梯度和专属 head 探针已实现并在 tiny 模型执行。
- [ ] 真实底座的完整分量梯度归因、随机探索与均值部署差距还需专门分析；head 探针不能替代它们。
