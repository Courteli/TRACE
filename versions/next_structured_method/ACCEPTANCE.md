# 新方法版验收清单

状态：全部待实施/待执行。以下为设计验收门槛，不是已有测试结果。

## 角色、目标与信息边界

- [ ] 默认总预算八角色；solve-role 数可配置，常量、头维度、索引、mask、checkpoint schema 一致。
- [ ] 每个教师转移恰好覆盖一次，分段连续不重叠；分段和等于终点减起点。
- [ ] 短 CoT、空区间、零范数及无有效步骤按显式规则处理，不产生 NaN 或虚假的方向监督。
- [ ] 角色 SFT、SOLVE 几何和过程评分使用同一份目标；学生/教师的基准状态和投影语义一致。
- [ ] 旧全角色路径目标不会被无意并行启用；PLAN 和 READOUT 不被当作额外文本分段。
- [ ] 推理入口不依赖金标准 CoT/答案/不可获得的依赖注释；移除训练标签不改变推理输入构造。

## 固定教师和 SFT

- [ ] 教师、tokenizer、数据、边界规则、固定投影和提取代码有真实指纹；错误缓存被拒绝。
- [ ] 学生更新前后，教师缓存内容和评分用头保持不变；学生预测头仍可训练。
- [ ] 均值路径和扰动路径共用动作机制；固定随机种子可重现，SFT 方差限制生效。
- [ ] 旧无效噪声配置被显式处理；不静默忽略也不叠加未声明噪声。
- [ ] 只生成/使用符合 split 约定的缓存，不将测试标签用于训练或模型选择。

## RL、概率与梯度

- [ ] 继承验证版的输入一致性、采样/log-prob、重放和 mask 测试。
- [ ] READOUT 为当前参数可微重算，非零答案优势可使其专属参数获得有限非零梯度。
- [ ] 随机角色动作可重放且概率条件一致；READOUT 不参加随机动作 loss。
- [ ] 末状态过程评分按声明向前传播，答案奖励不重复计数，组间无信息泄漏。
- [ ] 过程项尺度有界，微小差异不会被不受控放大；退火日程可测试、可恢复。
- [ ] loss 实现与固定尺度的明确公式一致；padding、长度、batch 切分及 DDP 不引入隐式重权。
- [ ] old log-prob 固定，角色参考/固定评分头身份独立保存，不被学生更新或恢复重建覆盖。
- [ ] 记录各损失和梯度贡献；分别检查随机策略与确定性均值推理，不将两者结果混用。
